# WPSComposer 0.8.1

Release date: 2026-09-07. Implementation baseline: `db6dd34`.

## Changes

Word operations activate a pinned, native WPS-created blank DOCX instead of `wpsDemo.docx`. The first M5 generation claims that exact private document; a relayout creates a fresh owned document in the same runtime. Generation and conversion start only the required component profile service in an isolated WPS host. Services close accepted connections and reclaim handler threads. Registration and document cleanup preserve unrelated user state.

`generate()` and `convert_to_pdf()` accept keyword-only `open_result=False`. Explicit presentation happens after successful publication and native cleanup. Launcher failure warns and returns the completed artifact. Existing unattended calls remain unchanged.

## Verification

- Real macOS WPS: DOCX generation, repeated PDF generation, standalone conversion, final DOCX automatic opening. Final pre-release pass: **62.734 seconds** for all four operations. Each used only Writer and a native blank activation document; registration bytes were restored, the profile port closed, and the pre-existing WPS host survived.
- An unrelated unsaved document remained unchanged and unsaved. The controller explicitly discarded only its own test document after verification.
- Controlled same-runtime relayout: **35.0 seconds**, one activation, two generations through one bridge, activation claims `[true, false]`. Only the first quality report was replaced to trigger relayout; rendering, saving and export used real WPS.
- Legacy Writer generation after isolation fix: **9.632 seconds**, `isolated=True`, one owned WPS host, valid output.
- Real HTTP tests cover keep-alive, idle and partial requests during shutdown; behavioral JS tests cover exact-path ownership, fresh JSAPI wrappers, registration failure disposal, and same-runtime relayout.
- Native seed: 10,223 bytes, SHA-256 `d5b2775d21547144c5e7e23f7efe36bcb5c161ff99962a1fda03a027a45ae994`; empty visible text, no fields, macros or external relationships.

## Boundaries

This release does not promise zero window flashes, persistent WPS daemons or dual-format output. Presentation/spreadsheet seeds remain unchanged. Their isolation arguments and the Windows launcher are covered by platform-independent tests; this release did not repeat their native platform acceptance. The pre-existing native heading-style mismatch remains a separate issue.
