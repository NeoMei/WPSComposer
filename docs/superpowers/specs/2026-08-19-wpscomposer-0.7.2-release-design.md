# WPSComposer 0.7.2 发布设计

## 目标

将 PR #3 中的表格零缩进、原生多级编号、原生目录、横向分节及相关回归修复作为补丁版本 `0.7.2` 发布到 `master`。

## 方案选择

- 采用：补丁版本 `0.7.2`。本次修复保持现有公共 API，符合语义化版本的补丁升级。
- 不采用：次版本 `0.8.0`。本次没有新增需要调用方适配的公共 API，不应放大版本级别。
- 不采用：仅更新 README、不更新包版本。该方案会造成代码与发布元数据漂移。

## 版本与文档

1. 将 `pyproject.toml` 的版本从 `0.7.1` 更新为 `0.7.2`。
2. 将 `.codex-plugin/plugin.json` 的版本从 `0.7.1` 更新为 `0.7.2`。
3. 在 README 更新日志顶部新增 `v0.7.2 (2026-08-19)`，说明：
   - WPS 表格单元格显式零缩进；
   - 与既有 `numbering.xml` 合并的原生多级编号；
   - 中文章号、十进制节号和关键工法编号联动；
   - 原生目录与横向图示分节；
   - 混合方向文档表格宽度和尾部空白页修复。

## 验证与发布

1. 检查两个版本源严格一致且 README 包含对应发布条目。
2. 运行完整测试套件，要求全部通过。
3. 检查提交差异，不包含未跟踪的 `uv.lock` 或客户文档。
4. 推送现有分支，更新 PR #3，转为 Ready for review。
5. 合并 PR #3 到 `master`，删除远端功能分支。
6. 拉取并核对远端 `master`：版本为 `0.7.2`、合并提交存在、测试结果与发布说明可追溯。

## 边界

- 不发布客户技术标或验收产物。
- 不修改与本轮 WPSComposer 修复无关的文件。
- 不创建 GitHub Release 或版本标签；用户当前要求是发布到 `master`。如需 Release/tag，另行执行。
