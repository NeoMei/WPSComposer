This static inventory follows the frozen 80 Word direct-method rows. After the two business-method slices, 40 names are declared by MacWordSession and 40 remain absent. Declaration is not native verification or complete argument support. Equivalent behavior exercised through the generation pipeline does not certify the same direct session method. Shared lifecycle, property, format, target and verb rows remain separate.

The newly declared style methods still reject character styles and unsupported properties explicitly. Representative new direct-method typography, section and field native acceptance is recorded in `macos-word-business/resume-03` and `macos-word-business-followup/resume-03`; complete argument combinations and attached-session behavior remain unverified. The Office.js supplement and Windows results do not automatically close these method rows.

The five object methods have a reviewed implementation and representative native acceptance in `macos-word-business-objects/run-05`: 21 named checks, including a nonempty unsaved sentinel, source-preserving reopen and native artifacts. Full argument parity remains open: floating-image alt text, unverified wrap values and floating image blocks are rejected before staging; raster variants not exercised natively are not certified.
