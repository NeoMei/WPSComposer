# Empty, custom and multisection defined-style matrix

All three source-only fixture probes return **STYLE_SUBSET_DIAGNOSED**. Each runs two identical native style snapshots, preserves saved/read-only/body and measured collection counts, retains source/private bytes, closes its exact copy and ends with independent Word inventory `[]`. The empty source has one empty paragraph and no numbering part/relationship. The nonempty source covers applied modified Heading2, modified but unused Heading3, custom paragraph/character, numbering-linked and unused custom styles. The multisection source adds three sections, a table cell and a styled field result. Deterministic generator/preflight and source fixtures are retained.

Word exposes 373 catalog entries / 4 definitions on empty and 376 / 9 on each rich fixture. The existing list-template count is zero on empty and one on both rich fixtures; it remains unchanged. Modified unused Heading3 appears among native definition rows, so that case is not lost by the candidate classifier.

Coverage remains incomplete: the linked custom character style is not independently exposed in the native catalog, and Word returns `automatically update=false` for Heading2/3 even though the source explicitly stores autoRedefine=true. Source-level flags and native runtime properties must remain separate. This matrix proves repeatable non-mutating reads of the native subset, not exhaustive OOXML style preservation. The production full-quality implementation remains unchanged; independent page-story and full combined snapshot requirements remain open.
