## Proposed production boundary

One new `skills/WPSComposer/scripts/msoffice/macos_word_quality.py` owns these four helper functions with `session` followed by the unchanged public arguments. Eventually add four lazy-import forwards with exact frozen public signatures. Leave writer.py, compiler, existing degradation/recovery/fields helpers, native fixture, and unrelated session behavior unchanged. If transport/binding changes are required, identify them to the parent before editing the shared file.

Within the focused helper, four native boundaries keep argument control flow independently testable:

- `_reserve_native(session) -> int`: exact document/window/selection.document and main-story guard; read actual bound selection End; create collapsed `wpsc_document_quality_anchor` and strictly acknowledge position, empty state and unchanged visible body. Does not choose a title, initialize dedup, or consume notices.
- `_target_at(session, position) -> target`: resolve/validate a collapsed numeric native range before display coercion, mirroring frozen `_doc.Range` timing. Descriptor carries exact bound document identity and actual range facts, not a COM proxy or a credential inferred from coordinates.
- `_target_bookmark(session, bookmark_name) -> target`: preserve native lookup semantics, default/falsy public anchor Start versus explicit bookmark first-paragraph End, and validate that target before message/page coercion. Do not invent a node-id resolver, replace a missing bookmark with document end, or silently clamp terminal positions.
- `_insert_box_native(session, target, display) -> NativeDegradationBox`: revalidate the descriptor's exact binding/current target facts in the mutating batch, run new geometry-specific insertion/recovery, require strict ACK, and return actual UTF-16 range/table facts. This boundary owns safe native display representability checks; wrappers retain the frozen order and public exception message.

These are proposed implementation boundaries, not test-only injection APIs. `test_macos_word_quality.py` doubles only these native boundaries and the equivalent Writer native methods. If code review chooses different names/ownership, adjust the test boundary coherently; do not add unused production hooks to appease tests. Transport ACK and failure tests must exercise the actual native compiler/parser separately.

## Python contract implementation order

1. Preserve `_quality_notice_seen` initialization before first title coercion. Title is `redact_private_text(str(title or default))`, only on first reservation and outside the reservation native `try`. Successful reservation stores numeric cursor and first title; an empty reservation remains invisible. Do not re-read an ignored replacement title.
2. Preserve `dict` versus object field reads: valid public code or `QUALITY_NOTICE`; placement remains its original value; node id uses dict `nodeId` / attribute `node_id`; identity uses redacted `str(node_id or "")`. Hash/duplicate check precedes message reads. Unhashable placement and getter/coercion errors outside the native `try` remain outside it.
3. Dict fallbackText wins only when truthy; object fallbackText/fallback are not read. Prepare a native numeric target before invoking `_degradation_display`. First title and first notice share one box; distinct identities each insert through the native box boundary. Cursor becomes returned Range.End; only then add identity to seen. Duplicate returns None without native work or message access.
4. `upsert` requires in-memory cursor before accessing issue fields. `add_document_quality_notice` reserves when missing, otherwise loops. Do not reconstruct dedup/title/cursor merely because a persisted bookmark exists. Every iterable is processed serially; failure of item two keeps a confirmed item one and does not consume item three. No batch-wide pre-materialization or rollback.
5. Bookmark notice ignores node_id, uses the resolved target before formatting `str(message)`, then `int(page)`, then `str(fallback)`, preserving redaction and native error wrapping. It never deduplicates or advances document-upsert cursor. Preserve coercions such as numeric strings, negative numbers, truncated finite floats and bool; do not enforce a new positive-integer schema. Invalid direct code falls back to `DEGRADATION`, not `QUALITY_NOTICE`.

Frozen public messages remain `quality anchor insertion failed`, `quality anchor is unavailable`, `quality notice upsert failed`, and `quality notice insertion failed`, all with code `DEGRADATION_INSERT_FAILED` in their original catches. Native uncertainty additionally retains evidence/quarantines before wrapping; no more AppleEvents may follow a timeout, cancellation, broken connection, malformed completion, unverified destructive cleanup or failed restoration.

## Native transaction implementation dependencies

- Reuse proven display/style constants, UTF-16 helper and immutable degradation DTOs. Do not pass a middle position to existing `range_commands`, `table_commands`, `_range_ack` or `_table_ack`: their append assumptions (`beforeEnd == position + 1`, last-table ordinal) must remain strict and unchanged.
- New target resolution must preserve Foundation exact comparison for paths, resolved native identity, code/text and structured preimages. Native name lookup case rules remain native behavior; exact canonical identity comparison is not a new case-sensitive input schema. Recheck exact bound path after any verified bound-window activation. Never read global selection as the owned target.
- New write batches go through the actual submission invalidation boundary (`_execute_topology_mutation` or its coordinated reviewed equivalent). Before-submission coercion, readonly/deadline or script-I/O failure leaves observed field topology intact. After any actual content-mutation submission, observations are invalid even when the native call fails or ACK is malformed. Success-only `_committed_range` invalidation is insufficient.
- Capture immutable full preimage including prefix/suffix hashes, all affected field/bookmark/table geometry and exact code/result identity, paragraph/character formatting and terminators at the insertion boundary. A private text hash is preferable to leaking full user body text into reports. The feasibility fixture's synthetic full-body observations are evidence, not a privacy policy for production diagnostics.
- Hold the newly created native table object inside one native batch. After a known ordinary creation/fill/style failure, delete only that owned object when its identity/current geometry is still verified. The middle run proves this one Delete can restore one paragraph-boundary insertion; it does not justify a generic Delete assumption. A before-creation failure authorizes fallback only after an acknowledged unchanged preimage, not merely because no object was returned.
- Require exact restored preimage before styled range fallback at the same original position. A stale target, unexpected table merge, crossing object, formatting/bookmark change, or different field identity stops the path and retains evidence. Never apply old append rollback to a middle insertion, delete a suffix, write captured text back wholesale, issue generic Undo or attempt CR repair automatically.
- New success ACK must bind exact target/document, actual content/range/cell geometry, actual table ordinal, required style values, before/after document delta and unaffected prefix/suffix objects. The existing total-table-count-as-ordinal logic cannot identify a middle table. No weakened ACK is justified by tests passing.
- Commit seen/cursor/title-return facts only after matching ACK. A local single-notice recovery can restore previous field observations only if their exact old topology is proved; otherwise they remain invalid. Do not restore old field snapshots simply because document length is back to its original number.

## Native position and failure matrix still required

The initial implementation may keep unproved positions closed **before mutation** with a typed limitation and retained explicit capability gap. This is a staging safety boundary, not removal of the required operation or a claim of parity. The final required contract still includes all positions supported by frozen Writer. Do not silently convert a failed/unproved target to an end-of-document insertion, add separators, normalize node placement, or change selection semantics.

| Required case | Why current primitive is insufficient | Gate to add |
| --- | --- | --- |
| Interior of a nonempty paragraph, including CJK/emoji and formatting runs | Only zero-width bookmark reservation was proved at interior offset 9; table insert/Delete can split paragraph and inherit styles | Actual table success, injected fill/style failure → exact restoration, range fallback, surrounding runs/paragraph marks and saved OOXML unchanged outside insertion |
| Noncollapsed bound selection | Frozen reserves at selection.End without deleting the selected text | Different active sentinel; real selected span preserved, reserve End verified, notice at End not Start |
| Existing table cell, including final cell/row terminators | New table may nest, merge, or target a different story/range; document-level table counts may omit nested tables | Native accepted target/lookup, table identity/nesting, cell boundary preservation and complete recovery; no claim based on body-only geometry |
| End of a normal paragraph and end of the final document paragraph | Explicit bookmark first-paragraph End may equal native document End, whereas append helpers use End−1 | Probe exact frozen position; no silent clamp; mandatory final CR, empty/nonempty terminal paragraphs and styled fallback verified |
| Adjacent tables and consecutive distinct upserts at prior Range.End | Word may merge adjacent tables; first proof had old tables separated by body text | Actual native topology/returned Range and preservation of all prior notice content; repeated reserve/upsert and title once, without relying on count+1 if native behavior differs |
| Default bookmark after document upserts | Public fixed bookmark may have different affinity than numeric cursor | Observe both native positions and then insert default bookmark notice independently; never replace both mechanisms with one moving bookmark |
| Explicit bookmark spanning multiple paragraphs; named/native ordinal input | Frozen target is first paragraph End, not entire bookmark End | Real lookup and first-paragraph readback; distinguish input normalization from resolved identity guard |
| Missing/stale bookmark, wrong app/document/path, after-before snapshot change | Passing fake descriptor integers is not target proof | Typed zero-mutation failures plus exact source/sentinel preservation |

## Prepared RED tests and what they do not prove

Separate literal oracle tests ensure expected cursors/title/dedup/error timing were not simply computed by the candidate. A frozen AST fingerprint guards the selected Writer oracle methods from drifting together with the candidate.

Prepared cases cover 20 semantic scenarios, 8 page coercions, four public signatures, and independent oracle checks. Expected RED is the missing Mac helper/forwards; these are intentionally active failing tests, not xfails or evidence of a numbering regression. They do **not** prove AppleScript binding/geometry, native ACK validation, truthful transport submission timing, rollback, read-only/deadline handling, native return DTO identity or native style. Those focused tests are dependencies of implementation before enabling methods.
